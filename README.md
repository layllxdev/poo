# ☕ Programação Orientada a Objetos

Repositório criado para organizar meus estudos, exercícios e projetos desenvolvidos durante a disciplina de **Programação Orientada a Objetos (POO)** na graduação em **Análise e Desenvolvimento de Sistemas**.

Aqui estão reunidas atividades realizadas em aula, listas de exercícios, testes e projetos desenvolvidos utilizando **Java** e conceitos de Programação Orientada a Objetos.

## 📚 Conteúdos

### 🧩 Fundamentos de POO

Os exercícios abordam conceitos fundamentais da Programação Orientada a Objetos, como:

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Construtores
* Herança
* Polimorfismo
* Abstração
* Interfaces
* Composição
* Associação entre classes
* Tratamento de exceções

### 🏫 Atividades em aula

A pasta `AtividadesEmAula` reúne exercícios desenvolvidos durante as aulas, incluindo exemplos envolvendo:

* Agendamentos
* Clientes
* Oficinas
* Serviços
* Veículos
* Processamento de pagamentos
* Pix
* Cartão
* Boleto
